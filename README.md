**Descripción del proyecto:** 

Sistema de control de inventario desarrollado en Python para gestionar las herramientas y stock de una ferretería en tiempo real. Permite realizar cargas, visualizar el inventario, consultar stock, generar reportes de productos agotados, dar de alta nuevos productos y actualizar existencias por ventas o ingresos, aplicando un estricto control de errores con try-except y rise.

**Arquitectura y archivos del código:**

- Principal.py (Menu principal y control de flujo).
- Cargar_herramientas.py (Carga inicial de datos).
- Mostrar_inventario.py (Visualización de productos).
- Consultar_stock.py (Busqueda de stock por nombre).
- Reporte_agotados.py (Filtro de stock en cero).
- Alta_producto.py (Registro de nuevos artículos).
- Actualizar_stock.py (Gestión de ventas e ingresos).
